# wave_01 scripts

Scripts only this wave needs - one-off analysis of its exports, data fixes for its dev runs, helpers too specific to justify a skill. Owned by the wave owner, changed on the wave's migration branch.

If a second wave needs one, move it to a skill's `scripts/` folder on a shared branch instead. Rules: Reusable scripts in `.claude/skills/talend-wave-migration/references/conventions.md`; `tests/static/test_scripts.py` checks the docstring and `--help`.
